
# Дәрілік препараттардың жарамдылық мерзімдерін бақылаудың ақпараттық жүйесі

Бұл жоба дәрілік препараттардың жарамдылық мерзімдерін бақылауға арналған ақпараттық жүйе болып табылады. Жүйе дәріхана қызметкерлеріне препараттарды тіркеуге, олардың жарамдылық мерзімдерін тексеруге және мерзімі аяқталуға жақындаған дәрілер туралы хабарлама алуға мүмкіндік береді.

## Мақсаты

Дәрілік препараттардың жарамдылық мерзімдерін автоматты түрде бақылау және мерзімі өткен препараттарды уақытында анықтау.

## Пайдаланушылар

- Әкімші
- Дәріхана қызметкері
- Қойма қызметкері

## Талаптар

1. Пайдаланушы жүйеге логин және құпиясөз арқылы кіре алады.
2. Әкімші пайдаланушыларды тіркеп, олардың рөлдерін басқара алады.
3. Дәріхана қызметкері жаңа дәрілік препаратты жүйеге енгізе алады.
4. Дәріхана қызметкері препараттың атауын, санын және жарамдылық мерзімін сақтай алады.
5. Жүйе деректер базасындағы дәрілердің жарамдылық мерзімдерін автоматты түрде тексереді.
6. Жүйе жарамдылық мерзімі аяқталуға жақындаған дәрілер туралы ескерту көрсетеді.
7. Қойма қызметкері мерзімі өткен препараттардың тізімін қарай алады.
8. Пайдаланушы препараттарды атауы немесе жарамдылық мерзімі бойынша іздей алады.
